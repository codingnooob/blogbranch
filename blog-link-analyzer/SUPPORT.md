# Support & Contact Information

## Get Help

We're here to help you get the most out of Blog Link Analyzer. Here are all the ways you can reach us for support, questions, or feedback.

## 🆘 Quick Help

### Common Issues & Solutions

**Extension not working?**
- Refresh the page and try again
- Check if you're on a supported blog platform
- Ensure you have the latest version installed

**AI features not responding?**
- Verify your API key is correct
- Check your internet connection
- Test your AI provider connection in settings

**Found a bug?**
- Check our [Troubleshooting Guide](USER_GUIDE.md#troubleshooting)
- Report the issue on GitHub with details

## 🐛 Bug Reports

### How to Report a Bug Effectively

1. **Check existing issues** first to avoid duplicates
2. **Use the bug report template** on GitHub
3. **Provide detailed information**:
   ```markdown
   ## Bug Description
   Brief description of what happened
   
   ## Steps to Reproduce
   1. Go to...
   2. Click on...
   3. See error...
   
   ## Expected Behavior
   What should have happened
   
   ## Actual Behavior
   What actually happened
   
   ## Environment
   - Browser: Chrome/Firefox version
   - OS: Windows/Mac/Linux
   - Extension Version: 1.0.0
   ```

4. **Include screenshots** or screen recordings if possible
5. **Check console errors** and include them in the report

## 📋 Frequently Asked Questions

### General Questions

**Q: Is the extension really free?**  
A: Yes! The core extension is free forever. AI features may require API costs from providers.

**Q: Do you collect my data?**  
A: No. All processing happens locally. Only AI features send content to providers you choose.

**Q: Which browsers are supported?**  
A: Chrome (v88+) and Firefox (v78+). Mobile support coming soon.

### Technical Questions

**Q: Why does it need `<all_urls>` permission?**  
A: To detect blogs on any website. We only analyze pages when you click the extension.

**Q: How do I uninstall?**  
A: Right-click the extension icon → Remove from browser, or use your browser's extensions page.

### AI Questions

**Q: Which AI provider is best?**  
A: OpenAI for speed, Anthropic for quality, Ollama for privacy.

**Q: Are my API keys secure?**  
A: Keys are stored locally and encrypted. We never see or store your keys.
