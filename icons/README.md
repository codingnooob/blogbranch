# Blog Link Analyzer Icons

This directory contains the extension icons in different sizes:

- icon16.png (16x16) - For browser toolbar
- icon48.png (48x48) - For extension management page
- icon128.png (128x128) - For Chrome Web Store

## Icon Design

The icons should represent:
- Blog/link analysis functionality
- Network/connections between blog posts
- Professional and modern appearance

## Current Status

Placeholder icons are needed. In a production environment, you would create:
1. SVG source files for scalability
2. PNG exports in required sizes
3. Proper color schemes for different browser themes

## Recommended Tools

- **Figma** or **Adobe Illustrator** for vector design
- **GIMP** or **Photoshop** for raster editing
- **Icon generators** for automated size conversion

## Icon Guidelines

- Use simple, recognizable shapes
- Ensure good contrast at small sizes
- Follow platform design guidelines
- Test on both light and dark themes
